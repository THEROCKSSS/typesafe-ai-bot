Getting it on your server

Five minutes. Four commands.

bash — typesafe-ai-bot
$ git clone <repo> typesafe-ai-bot
$ pip install -r requirements.txt
$ cp .env.example .env # paste your bot token
$ python src/main.py # DRY_RUN=1 to watch first
[bot] KDF Command ready · enforcement: watch-only
$ python src/dashboard_main.py # → 127.0.0.1:8788
Watch before you act

Start in DRY_RUN: the bot screens and logs every judgment but applies nothing. Flip enforcement on when you trust it.

Degrades safely, never silently

No AI credits? No outage surprises. It falls back to flags-for-human-review and says so on the dashboard — it never auto-punishes on a guess.

Your data stays yours

Cases live in a local SQLite file. The dashboard runs on your machine. The Discord token never leaves your server process.

Bring your own rules

The rulebook is a JSON file you edit. Add a rule, and it becomes a judgment the AI reads every message against.
